# Plan 7.1: Pre-Parsed Frame Array & Zero-Drift Silence Engine

## Objective
Eliminate MP3 frame boundary slicing errors and loop wrap-around corruption in the silence streaming loop by implementing a deterministic MPEG-1 Layer 3 frame parser and pre-indexed frame array in `PersistentStreamManager`.

## Context
- .gsd/SPEC.md
- .gsd/phases/7/RESEARCH.md
- scratch/cloud_persistentStreamManager.js
- assets/silence_96k.mp3

## Tasks

<task type="auto">
  <name>Build MP3 Frame Parser & Validator</name>
  <files>src/audio/mp3FrameParser.js</files>
  <action>
    Create a lightweight, zero-dependency MPEG Layer 3 frame parser utility in `src/audio/mp3FrameParser.js`:
    - Implement `parseMp3Frames(buffer)`: scans for MPEG-1 Layer 3 sync word (`0xFF` followed by `0xFB` or `(b1 & 0xE0) === 0xE0`).
    - Calculates exact frame length per ISO formula: `Math.floor(144 * bitrate / sampleRate) + paddingBit` (handling 313 vs 314 bytes at 96k/44.1k).
    - Returns an array of independent `Buffer` slices representing each intact frame.
    - Exports `stripId3v2(buffer)` to skip any ID3v2 metadata prefix before the first audio frame.
  </action>
  <verify>
    node -e "
      import('./src/audio/mp3FrameParser.js').then(m => {
        const dummy = Buffer.alloc(1000);
        console.log('mp3FrameParser loaded successfully');
      });
    "
  </verify>
  <done>
    `src/audio/mp3FrameParser.js` exists, parses MPEG-1 Layer 3 headers, and returns an array of complete frames.
  </done>
</task>

<task type="auto">
  <name>Refactor Silence Engine to Use Pre-Parsed Frame Array</name>
  <files>scratch/cloud_persistentStreamManager.js</files>
  <action>
    Update `scratch/cloud_persistentStreamManager.js`:
    - In `init()`: After generating or reading `silence_96k.mp3`, pass the buffer through the frame parser to create `this.silenceFrames = []`.
    - Log the count of parsed frames (e.g. `Loaded 191 intact MPEG Layer 3 frames (313/314 bytes)`).
    - In `startSilenceFeed()`: Replace arbitrary `CHUNK_SIZE = 1200` slicing and byte offset math with `this.silenceFrameIndex`.
    - Each tick, pick the next frame: `const frame = this.silenceFrames[this.silenceFrameIndex % this.silenceFrames.length]`.
    - Advance `this.silenceFrameIndex++`.
    - Pacing: At 96k/44.1k, each frame represents exactly 1152 samples = ~26.122ms of audio. Calculate target frames using high-resolution time (`hrtime.bigint()`).
  </action>
  <verify>

      });

  </verify>
  <done>
    `PersistentStreamManager` streams silence by rotating through pre-indexed whole frames with 0% frame drift and clean wrap-around.
  </done>
</task>

## Success Criteria
- [ ] Every chunk broadcast during silence starts with valid MPEG Layer 3 sync header (`0xFF 0xFB`).
- [ ] Wrapping around the silence loop does not drop or corrupt any partial frame.
- [ ] Frame rate accurately matches 38.28 frames per second (26.12ms per frame).
