# Plan 7.2: Clean Track EOF Frame Alignment & Burst Buffer Isolation

## Objective
Eliminate the track-end audio pause/gap in `AudioPlayer` by ensuring music streams terminate on exact MP3 frame boundaries rather than cut-off byte chunks, and isolate burst buffer chunks in memory.

## Context
- .gsd/SPEC.md
- .gsd/phases/7/RESEARCH.md
- scratch/cloud_audioPlayer.js
- src/audio/mp3FrameParser.js

## Tasks

<task type="auto">
  <name>Implement Clean Frame Boundary EOF Truncation</name>
  <files>scratch/cloud_audioPlayer.js</files>
  <action>
    Update `scratch/cloud_audioPlayer.js`:
    - Before beginning streaming in `play()`: Scan the pre-encoded MP3 file to identify the byte offset of the last complete MP3 frame.
    - Set `effectiveFileSize` to the end of that last complete frame, ignoring any trailing partial frame or ID3v1 metadata tag (last 128 bytes of file if present).
    - When `fileOffset + bytesRead >= effectiveFileSize`, trim the final chunk to end at `effectiveFileSize` exactly.
    - Result: The music track ends on a 100% complete MP3 frame. When `resumeSilenceFeed()` fires immediately after, the client decoder transitions directly to the next frame header (`0xFF 0xFB`) without encountering corrupted or partial data.
  </action>
  <verify>
    node -e "
      import('./scratch/cloud_audioPlayer.js').then(m => {
        const ap = new m.AudioPlayer(null);
        console.log('AudioPlayer loaded');
      });
    "
  </verify>
  <done>
    `AudioPlayer` streams only full MP3 frames up to `effectiveFileSize` and never emits fractional frames at track ends.
  </done>
</task>

<task type="auto">
  <name>Isolate Burst Buffer Chunks with Memory Cloning</name>
  <files>scratch/cloud_audioPlayer.js</files>
  <action>
    Fix the in-place memory mutation bug in `cloud_audioPlayer.js`:
    - Locate line 199 where `readBuffer` is sliced:
      `const slice = bytesRead === CHUNK_SIZE ? readBuffer : readBuffer.subarray(0, bytesRead);`
    - Replace with explicit cloning:
      `const slice = Buffer.from(readBuffer.subarray(0, bytesRead));`
    - This guarantees that each chunk stored in `this.streamManager.audioBuffer` (the 12KB burst buffer) retains its own immutable memory and is not overwritten by subsequent disk reads.
  </action>
  <verify>
    node -e "
      import('./scratch/cloud_audioPlayer.js').then(m => {
        console.log('AudioPlayer memory isolation syntax valid');
      });
    "
  </verify>
  <done>
    `readBuffer` chunks are cloned independently with `Buffer.from()` before passing to `streamManager.broadcast()`.
  </done>
</task>

## Success Criteria
- [ ] Music playback terminates on a clean MP3 frame boundary with 0 trailing partial bytes.
- [ ] Burst buffer holds distinct audio chunks without memory corruption or overwrite.
- [ ] Decoder transitions seamlessly from track EOF into silence feed with 0ms mute duration.
