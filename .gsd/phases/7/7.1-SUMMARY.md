## 1. Executive Summary

Plan 7.1 resolves the MP3 frame boundary slicing errors and silence loop wrap-around corruption in the streaming fleet. By implementing a deterministic MPEG Layer 3 frame parser utility and refactoring `PersistentStreamManager` to rotate through an array of pre-parsed intact frames, all outgoing chunks are guaranteed to begin with a valid MPEG sync header (`0xFF 0xFB`), eliminating decoder desync and audio glitches during idle silence playback.

---

## 2. Changes Delivered

### Task 1: Build MP3 Frame Parser & Validator (`src/audio/mp3FrameParser.js`)
- Created a zero-dependency MPEG Layer 3 frame parser with ISO frame length calculation:
  $$\text{FrameLength} = \left\lfloor \frac{144 \times \text{Bitrate}}{\text{SampleRate}} \right\rfloor + \text{PaddingBit}$$
- Handled alternating 313-byte and 314-byte frames for 96kbps CBR at 44.1kHz.
- Implemented `stripId3v2(buffer)` to locate and bypass ID3v2 headers via 4-byte syncsafe integer size extraction.
- Implemented `parseMp3Frames(buffer)` to scan sync words (`0xFF` with `(b1 & 0xE0) === 0xE0`), validate MPEG-1 Layer 3 parameters, omit incomplete trailing half-frames at EOF, and return an array of independent cloned frame buffers.
- Verified frame extraction against 96k CBR MP3 buffers.

### Task 2: Refactor Silence Engine (`scratch/cloud_persistentStreamManager.js`)
- In `init()`: Passed the silence buffer into `parseMp3Frames()` to populate `this.silenceFrames = []`, safely loading 40+ intact frames (313/314 bytes).
- In `startSilenceFeed()`: Eliminated arbitrary `CHUNK_SIZE = 1200` byte-slicing and offset pointer arithmetic. Replaced with `this.silenceFrameIndex`.
- Implemented frame-by-frame rotation: `const frame = this.silenceFrames[this.silenceFrameIndex % this.silenceFrames.length]`.
- Enforced high-resolution nanosecond pacing via `process.hrtime.bigint()` based on exact frame duration (1152 samples / 44,100Hz = ~26.122ms per frame).
- Synchronized idle silence tracking when no listeners are attached to prevent catchup burst storms.
